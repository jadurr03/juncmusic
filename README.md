# JUNC Music

Official-ish archive of JUNC.

This site intentionally uses an early-2000s independent-band / GeoCities visual language while remaining readable on modern phones.

## v0.1

- Static HTML/CSS/JS
- GitHub Pages friendly
- Responsive underneath the retro layout
- Placeholder sections for band history, music, shows, photos, archive, JUNC Labs, and guestbook

Historical artifacts and actual content will replace placeholders over time.

> Best viewed at 1024×768. Internet Explorer 6 recommended. Netscape users: good luck.
